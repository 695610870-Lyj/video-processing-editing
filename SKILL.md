# video-processing-editing

Video processing and editing skill for OpenClaw.

## Description

Use this skill when you need to:
- Process video files (transcode, resize, trim)
- Extract frames from videos
- Add subtitles or watermarks
- Convert video formats
- Analyze video metadata

## Tools

This skill provides video processing capabilities using FFmpeg and other tools.

## Usage

The skill will be automatically loaded when video-related tasks are detected.
